# 中欣工具箱

目标网址：<https://zx-toolbox.netlify.app>

中欣工具箱面向电机设计、绕线与生产校核，将槽极配、漆包线排线和线圈电阻计算集中到一个静态网站。

> 当前状态：四个路由和三项计算工具均已实现。槽极配支持手动节距与每相并联支路选择；漆包线排线严格沿用工作簿公式、默认值和业务警告；线圈电阻沿用工作簿公式，输入由用户填写，计算结果按字段即时显示。

## 工具范围

| 工具 | 目标路由 | 计算来源 | 主要输出 |
| --- | --- | --- | --- |
| 槽极配生成器 | `/slot-pole` | 现有网站算法 | 推荐节距、线圈接线表、三相接线图 |
| 漆包线排线计算器 | `/wire-layout` | `漆包线排线计算器.xlsx` | 密排尺寸、可排层数、根数和剩余量 |
| 线圈电阻计算器 | `/coil-resistance` | `线圈电阻计算.xlsx` 扩展 | 线材长度、铜/铝线圈电阻、单线圈与三相整机重量 |

首页 `/` 显示“中欣工具箱”和三个工具入口，并保留“更多工具”扩展位置。

## 计算规则

### 槽极配生成器

保留现有三相双层绕组逻辑：

- 槽数 `Q` 为 3 至 120 的整数，且为 3 的倍数。
- 总极数 `P` 为 2 至 120 的偶数。
- 推荐节距 `y = floor(Q / P)`，最小为 1。
- 可手动输入整数节距 `1 ≤ y < Q`，实际槽对及电角随节距重算；零基波节距不生成接线。
- 自动列出每相等效并联支路数；仅能串联时只显示 `1（全部串联）`。例如12槽10极、节距1可选1/2路，36槽4极、节距9可选1/2/4路，9槽8极、节距1仅串联。
- 并联计算假定同匝数、同线径及对称磁场，按极性修正后的电角分类均分线圈，各支路包含相同类别及数量；不对称三相给出提示，仅保留串联示意。
- 改变槽数、极数或节距后支路数重置为1；选择支路后，表格、展开接线图与端子说明同步更新。
- 支持 `ABC`、`UVW` 和 BC/VW 相别互换。
- 输出相别、线圈标记、槽对、极性、电角度、支路及路内顺序、串并联路线和中性点。展开图保持等尺寸线圈，图形宽度不代表节距，实际槽对以标注为准。

### 漆包线排线计算器

严格复刻 Excel 的圆形漆包线梅花形密排模型。`D` 使用含漆膜实际外径，所有尺寸单位为 `mm`。

公共几何：

```text
垂直层间距 Pv = D × √3 / 2
水平错位量 Offset = D / 2
垂直总高度 H = D + (M - 1) × Pv
```

支持两种计算方式：

1. 按层数计算尺寸：输入 `D`、垂直层数 `M`、水平根数 `N` 和排布模式，输出高度、宽度与总根数。
2. 按最大尺寸反推：输入 `D`、最大宽度 `Wmax`、最大厚度 `Tmax` 和排布模式，输出不超过边界的层数、根数、实际尺寸和剩余量。

排布模式保持 Excel 原定义：

- 每层同根数：每层均排 `N` 根，多层时水平包络增加 `D / 2`。
- 边界内错排：奇数层排 `N` 根，偶数层排 `N - 1` 根。

不增加全局最优搜索、压扁修正、张力修正、漆膜公差、浸漆或工艺余量。

### 线圈电阻计算器

保留 Excel 的圆形与矩形线圈几何、电阻和接法公式，并扩展固定材料选择与重量计算：

- 圆形线圈：根据材料、裸线径、内外圈直径和匝数计算平均匝长、线材长度、单线圈电阻与重量。
- 矩形线圈：根据材料、内外圈长宽、匝数、每相支路数和每支路线圈数计算单线圈、单相及 P-P 电阻，并计算整台三相电机线圈重量。
- 材料只允许铜线和铝线；铜线电阻率为 `17.24 μΩ·mm`、密度为 `8.96 × 10⁻⁶ kg/mm³`，铝线电阻率为 `27.57 μΩ·mm`、密度为 `2.70 × 10⁻⁶ kg/mm³`。
- 页面不预填线径、尺寸、匝数、支路数或线圈数；两个材料选择均默认铜线。

公共公式：

```text
导体截面积 A = π × (d / 2)²
电阻 R = ρ × L / A / 1,000,000
单线圈重量 = A × L × 材料密度
整台三相电机线圈重量 = 单线圈重量 × 3 × 每相支路数 × 每支路线圈数
```

实现时使用工作簿原常量：圆形线圈 `π = 3.141592653`，电机线圈截面积 `π = 3.1415926535`，不替换成语言内置 `Math.PI`。

电机线圈继续使用：

```text
单相电阻 = 单线圈电阻 × 每支路线圈数 / 每相支路数
P-P 电阻 = 2 × 单相电阻
```

该 P-P 公式保持原表的三相对称、星形接法假设，不增加温度和接法选项。

有效数值输入继续使用工作簿几何与电阻公式；工作簿示例只作为回归测试，不再预填到线圈电阻页面。重量只计算裸导体，不包含漆皮、引出线、跨接线、接头、浸漆或工艺余量。

## 页面结构

```text
/
├── slot-pole
├── wire-layout
└── coil-resistance
```

- 首页负责品牌、工具发现和导航。
- 每个计算器拥有独立路由、元数据、计算模块和测试。
- 计算全部在浏览器本地完成，不依赖数据库、账号或远程 API。
- 首页通过统一工具注册表生成入口，后续添加工具不改首页结构。

## 首页交互

- 桌面端默认突出槽极配生成器。
- 鼠标移入或键盘聚焦任一工具时，该工具在约 `540ms` 内扩展为主功能区，其余工具同步收缩。
- 动效使用 `cubic-bezier(.22, 1, .36, 1)`，只表达当前焦点。
- `prefers-reduced-motion: reduce` 下取消位移和延迟。
- 移动端纵向排列完整摘要，点击直接进入工具，不依赖悬停。

## 实现结构

- 根布局提供统一导航、页脚、品牌元数据和站点结构化数据。
- 首页从统一工具注册表生成三个入口；桌面端支持悬停/聚焦扩展，移动端改为完整纵向卡片。
- 三个工具使用独立路由、计算模块、样式和回归测试，互不共享业务状态。
- 计算全部在浏览器本地完成；静态导出可直接发布到 Netlify。

## 本地运行

需要 Node.js `>= 22.13.0` 与 pnpm。

```bash
pnpm install
pnpm dev
```

## 验证与构建

```bash
pnpm test
pnpm lint
pnpm build
pnpm test:build
```

项目使用静态导出，Netlify 发布目录为 `dist/client`。测试覆盖工作簿示例值、边界输入、首页注册表、SEO 与最终静态 HTML。

Windows + Node 24 下，构建命令会预加载 `scripts/vinext-windows-exit-shim.mjs`，规避 Vinext 0.0.50 在预渲染服务器已关闭后立即强制退出所触发的 libuv 断言；仅成功退出会改为自然排空，真实构建错误仍保持非零退出码。其他平台不受影响。

本轮桌面、键盘和移动端的实机检查见 [浏览器验收记录](docs/qa/2026-07-27-zx-toolbox-browser-qa.md)。
