# 中欣工具箱

目标网址：<https://zx-toolbox.netlify.app>

中欣工具箱面向电机设计、绕线与生产校核，将槽极配、漆包线排线和线圈电阻计算集中到一个静态网站。

> 当前状态：四个路由和三项计算工具均已实现。槽极配保留原算法，漆包线排线与线圈电阻严格沿用工作簿公式、默认值和业务警告。

## 工具范围

| 工具 | 目标路由 | 计算来源 | 主要输出 |
| --- | --- | --- | --- |
| 槽极配生成器 | `/slot-pole` | 现有网站算法 | 推荐节距、线圈接线表、三相接线图 |
| 漆包线排线计算器 | `/wire-layout` | `漆包线排线计算器.xlsx` | 密排尺寸、可排层数、根数和剩余量 |
| 线圈电阻计算器 | `/coil-resistance` | `线圈电阻计算.xlsx` | 铜线长度、单线圈电阻、单相与 P-P 电阻 |

首页 `/` 显示“中欣工具箱”和三个工具入口，并保留“更多工具”扩展位置。

## 计算规则

### 槽极配生成器

保留现有三相双层绕组逻辑：

- 槽数 `Q` 为 3 至 120 的整数，且为 3 的倍数。
- 总极数 `P` 为 2 至 120 的偶数。
- 推荐节距 `y = floor(Q / P)`，最小为 1。
- 支持 `ABC`、`UVW` 和 BC/VW 相别互换。
- 输出相别、线圈标记、极性、电角度、串联路线和中性点。

### 漆包线排线计算器

严格复刻 Excel 的圆形漆包线梅花形密排模型。`D` 使用含漆膜实际外径，所有尺寸单位为 `mm`。

公共几何：

```text
垂直层间距 Pv = D × √3 / 2
水平错位量 Offset = D / 2
垂直总高度 H = D + (M - 1) × Pv
```

支持两种计算方式：

1. 按层数计算尺寸：输入 `D`、垂直层数 `M`、水平根数 `N` 和排布模式，输出高度、宽度与总根数。
2. 按最大尺寸反推：输入 `D`、最大宽度 `Wmax`、最大厚度 `Tmax` 和排布模式，输出不超过边界的层数、根数、实际尺寸和剩余量。

排布模式保持 Excel 原定义：

- 每层同根数：每层均排 `N` 根，多层时水平包络增加 `D / 2`。
- 边界内错排：奇数层排 `N` 根，偶数层排 `N - 1` 根。

不增加全局最优搜索、压扁修正、张力修正、漆膜公差、浸漆或工艺余量。

### 线圈电阻计算器

严格复刻 Excel 的两种模型：

- 圆形线圈：根据裸线径、内外圈直径和匝数计算平均匝长、铜线长度与单线圈电阻。
- 电机线圈：根据内外圈长宽、匝数、电阻率、每相支路数和每支路线圈数计算单线圈、单相与 P-P 电阻。

公共公式：

```text
导体截面积 A = π × (d / 2)²
电阻 R = ρ × L / A / 1,000,000
```

实现时使用工作簿原常量：圆形线圈 `π = 3.141592653`，电机线圈截面积 `π = 3.1415926535`，不替换成语言内置 `Math.PI`。

电机线圈继续使用：

```text
单相电阻 = 单线圈电阻 × 每支路线圈数 / 每相支路数
P-P 电阻 = 2 × 单相电阻
```

该 P-P 公式保持原表的三相对称、星形接法假设，不增加温度和接法选项。

“严格复刻”指有效数值输入下的公式、默认值、结果和业务警告一致。网页允许改善字段提示、数字排版和无效输入错误，但不改变有效输入的计算结果。

## 页面结构

```text
/
├── slot-pole
├── wire-layout
└── coil-resistance
```

- 首页负责品牌、工具发现和导航。
- 每个计算器拥有独立路由、元数据、计算模块和测试。
- 计算全部在浏览器本地完成，不依赖数据库、账号或远程 API。
- 首页通过统一工具注册表生成入口，后续添加工具不改首页结构。

## 首页交互

- 桌面端默认突出槽极配生成器。
- 鼠标移入或键盘聚焦任一工具时，该工具在约 `540ms` 内扩展为主功能区，其余工具同步收缩。
- 动效使用 `cubic-bezier(.22, 1, .36, 1)`，只表达当前焦点。
- `prefers-reduced-motion: reduce` 下取消位移和延迟。
- 移动端纵向排列完整摘要，点击直接进入工具，不依赖悬停。

## 实现结构

- 根布局提供统一导航、页脚、品牌元数据和站点结构化数据。
- 首页从统一工具注册表生成三个入口；桌面端支持悬停/聚焦扩展，移动端改为完整纵向卡片。
- 三个工具使用独立路由、计算模块、样式和回归测试，互不共享业务状态。
- 计算全部在浏览器本地完成；静态导出可直接发布到 Netlify。

## 本地运行

需要 Node.js `>= 22.13.0` 与 pnpm。

```bash
pnpm install
pnpm dev
```

## 验证与构建

```bash
pnpm test

pnpm build
pnpm test:build
```

项目使用静态导出，Netlify 发布目录为 `dist/client`。测试覆盖工作簿默认值、边界输入、首页注册表、SEO 与最终静态 HTML。

本轮桌面、键盘和移动端的实机检查见 [浏览器验收记录](docs/qa/2026-07-27-zx-toolbox-browser-qa.md)。
