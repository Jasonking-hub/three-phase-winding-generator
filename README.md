# 槽极配生成器

在线使用：<https://three-phase-winding-generator.netlify.app>

面向三相双层绕组设计与学习的槽极配合计算工具。输入槽数和总极数，即可生成绕组相别、线圈标记、接线顺序与三相端子信息。

## 能做什么

- 计算三相绕组槽极配，判断输入参数是否可生成。
- 根据槽数 `Q` 与总极数 `P` 给出推荐节距。
- 输出完整线圈接线表：相别、线圈标记、组极性和电角度。
- 显示可缩放三相接线图，包含串联路径、端子和中性点 `N`。
- 支持 `ABC` 与 `UVW` 两种相别记法，以及 `BC` / `VW` 相别互换。

## 适用场景

- 三相双层绕组槽极配快速计算。
- 电机绕组设计、课堂学习和接线核对。
- 将槽极配、节距和三相端子关系可视化，减少手工排表错误。

## 使用方法

1. 输入槽数 `Q`：3 至 120 的整数，且为 3 的倍数。
2. 输入总极数 `P`：2 至 120 的偶数。
3. 选择相别显示方式；需要时启用 BC 相互换。
4. 查看推荐节距、线圈接线表和三相接线图。

## 本地运行

需要 Node.js `>= 22.13.0` 与 pnpm。

```bash
pnpm install
pnpm dev
```

访问本地开发服务器显示的地址。

## 验证与构建

```bash
pnpm test
pnpm build
```

项目使用静态导出，Netlify 发布目录为 `dist/client`。部署配置见 [netlify.toml](netlify.toml)。
