# 中欣工具箱浏览器验收记录

日期：2026-07-27  
环境：Windows、Chromium、Vinext 开发服务器、桌面默认视口与 390 × 844 移动视口。

## 已验证

- 首页桌面端默认突出槽极配；聚焦漆包线排线入口后，活动宽度由 `105px` 扩展到 `229px`，其余两项为 `105px`，焦点轮廓可见。
- 聚焦漆包线排线入口后按 Space，地址正确进入 `/wire-layout`。
- 390px 视口下三个入口纵向显示完整卡片；页面 `clientWidth` 与 `scrollWidth` 均为 `375px`，无页面级横向溢出。
- 漆包线排线输入由 `0.87` 改为 `0.871` 后，页面即时更新层间距、总高度和总宽度，证明客户端水合与计算交互生效。
- 首页、排线页和电阻页均完成视觉检查；排线预览为白底橙色描边的真实错排圆线，左、下边界清晰可见。
- 重启开发服务器后重新访问，所检查页面的浏览器 console 无 error 或 warning。

## 静态与代码约束

- `prefers-reduced-motion: reduce` 分支取消卡片 transition 和位移；该环境未提供媒体偏好模拟能力，因此以样式审查确认。
- hover 与 focus 共用同一 `activeId` 更新路径；本轮通过真实 focus 验证扩展，hover 已在交互确认阶段由人工页面操作验收。
