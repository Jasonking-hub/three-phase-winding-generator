## 静态与代码约束

- 自动化浏览器实际为 `prefers-reduced-motion: reduce`，生产 CSS 将工具轨道 transition 解析为 `none`；该环境未发生动画。临时移除该媒体覆盖后诊断普通 motion，计算 transition 为 `grid-template-columns 0.65s cubic-bezier(0.16, 1, 0.3, 1)`，聚焦排线卡时列宽从起始 `507.4px`、`303.9px`、`253.5px`，经 `70ms` 的 `354.8px`、`456.5px`、`253.5px` 与 `230ms` 的 `266.4px`、`544.9px`、`253.5px`，至 `680ms` 的 `253.5px`、`557.8px`、`253.5px`，确认连续插值而非瞬时跳变；诊断后已恢复文件。
- hover 与 focus 共用同一 `setActiveId` 状态路径；本轮通过真实 focus 验证工具轨道扩展，hover 复用同一路径。各链接 `aria-label` 唯一，重复视觉层均不进入辅助功能树；Space 行为保留先前浏览器验收覆盖。
