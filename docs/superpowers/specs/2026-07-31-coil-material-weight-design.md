# 线圈材料与重量计算设计规格

## 1. 目标

扩展 `/coil-resistance` 的圆形线圈与矩形线圈计算：

- 用“线圈材料”选择替代可编辑或固定的铜线电阻率。
- 支持铜线、铝线，默认铜线。
- 两个计算区不预填线径、尺寸、匝数、支路数或线圈数。
- 忽略漆皮、引出线、跨接线和接头重量。
- 圆形线圈显示单线圈重量。
- 矩形线圈显示单线圈重量和整台三相电机线圈重量。
- 所有重量统一显示为 `kg`。

本次不增加温度修正、自定义材料、自定义密度或自定义电阻率。

本规格覆盖 `2026-07-27-zx-toolbox-design.md` 中线圈电阻计算器的默认数值输入要求。原工作簿示例继续作为回归测试数据，但不再预填到页面。

## 2. 材料定义

纯计算模块维护唯一材料表，页面只传材料标识：

| 材料标识 | 页面名称 | 电阻率 | 密度原值 | 计算密度 |
| --- | --- | --- | --- | --- |
| `copper` | 铜线 | `17.24 μΩ·mm` | `8.96 g/cm³` | `8.96 × 10⁻⁶ kg/mm³` |
| `aluminum` | 铝线 | `27.57 μΩ·mm` | `2700 kg/m³` | `2.70 × 10⁻⁶ kg/mm³` |

材料标识只允许 `copper` 和 `aluminum`。无效标识返回字段错误，不回退到铜线。

## 3. 计算模型

### 3.1 公共规则

现有几何公式、圆周率常量和电阻接法公式保持不变。

```text
单线圈体积 V = 裸线截面积 A(mm²) × 单线圈线材长度 L(mm)
单线圈重量 Mcoil(kg) = V(mm³) × 材料密度(kg/mm³)
单线圈电阻 Rcoil(Ω) = 材料电阻率 × L / A / 1,000,000
```

重量仅包含裸导体。漆皮以及未计入现有线长模型的附加导线均不计算。

### 3.2 圆形线圈

输入新增 `material`，默认 `copper`。线径、内外圈直径和匝数初始为空。原固定铜线电阻率改为从材料表读取。

输出新增：

```text
单线圈重量 Mcoil
```

使用原工作簿圆形线圈示例数据时，铜线重量预期为：

```text
0.12847920838611958 kg
```

相同几何尺寸选择铝线时：

```text
单线圈电阻 = 4.628737006181134 Ω
单线圈重量 = 0.038715832884210144 kg
```

### 3.3 矩形线圈

输入删除可编辑 `resistivity`，新增 `material`，默认 `copper`。线径、内外圈长宽、匝数、每相支路数和每支路线圈数初始为空。每相支路数和每支路线圈数继续同时参与原电阻公式与新增总重量公式。

```text
单线圈重量 Mcoil = A × L × density
整机线圈数 Ntotal = 3 × 每相支路数 × 每支路线圈数
整台三相电机线圈重量 Mtotal = Mcoil × Ntotal
```

原电阻公式保持：

```text
单相电阻 Rphase = Rcoil × 每支路线圈数 / 每相支路数
P-P 电阻 = 2 × Rphase
```

使用原工作簿矩形线圈示例数据、铜线、每相一支路、每支路一个线圈时：

```text
单线圈重量 = 0.06480049063729275 kg
整台三相电机线圈重量 = 0.19440147191187823 kg
```

相同输入选择铝线时：

```text
单线圈电阻 = 0.7891641353432389 Ω
单线圈重量 = 0.019526933562577057 kg
整台三相电机线圈重量 = 0.05858080068773117 kg
```

## 4. 页面与交互

圆形线圈区和矩形线圈区各自维护独立材料选择，互不联动，默认均为铜线。

两个计算区的数值输入初始均为空。首次打开页面时，结果区显示待输入提示，不显示计算结果，也不立即显示字段错误。用户开始填写后，沿用现有字段级校验；只有全部必填数值有效时才显示结果。

材料选择使用原生 `select` 或等价的单选控件，提供可见标签“线圈材料”，选项为“铜线”和“铝线”。控件遵守：

- `DESIGN.md` Section 4 “输入与选择器”：Editable Input 背景、Structural Line 边框、Brand Orange 焦点状态、最小高度 `44px`。
- `DESIGN.md` Section 8：触摸目标、单列断点和页面无横向溢出规则。

结果标签改为材料中立文案：

- “铜线长度”改为“单线圈线材长度”。
- 圆形线圈新增“单线圈重量”。
- 矩形线圈新增“单线圈重量”和“整台三相电机线圈重量”。
- 重量使用与电阻一致的六位小数格式，单位为 `kg`。

页面介绍、工具注册表和线圈电阻页 SEO 文案不再限定为铜线，明确支持铜线与铝线。

保留当前工作区已有的“矩形线圈”命名和删除计算区后独立假设说明块的改动。

## 5. 模块边界与数据流

`app/coil-resistance/coil-resistance.js` 负责：

- 材料常量和材料标识验证。
- 根据材料选择电阻率与密度。
- 电阻、单线圈重量和整机重量计算。
- 重量格式化。

`app/coil-resistance/CoilResistanceCalculator.tsx` 负责：

- 两个计算区的材料选择状态。
- 字符串输入解析。
- 材料选择控件和材料中立文案。
- 渲染重量结果。

数据流：

```text
材料选择与数值输入
  -> 页面保留材料标识并解析数值
  -> 纯函数验证材料和数值
  -> 材料表解析电阻率与密度
  -> 计算电阻与重量
  -> 页面格式化显示
```

## 6. 错误处理

- 数值字段继续沿用现有大于零、有限数和整数校验。
- 删除 `resistivity` 数值校验，因为该输入不再存在。
- 无效材料返回 `errors.material = "请选择有效材料。"`，结果为 `null`。
- 页面始终提供两个合法材料选项；纯函数仍独立防御非法调用。
- 一个计算区无效不影响另一个计算区。
- 初始空表单属于未开始状态，不等同于错误状态；字段错误只在用户编辑相应计算区后显示。

## 7. 测试与验收

### 纯函数测试

- 原工作簿铜线示例的电阻结果保持不变。
- 圆形线圈铜、铝重量与本规格精确值在浮点容差内一致。
- 矩形线圈铜、铝电阻、单线圈重量与整机重量正确。
- 整机重量随 `每相支路数 × 每支路线圈数 × 3` 成比例变化。
- 单相电阻仍按 `每支路线圈数 / 每相支路数` 变化。
- 无效材料被拒绝。
- 删除对可编辑 `resistivity` 的输入与错误断言。
- 重量格式化为六位小数，非有限值显示 `—`。

### 页面与构建测试

- 两个计算区均存在默认值为铜线的材料选择。
- 两个计算区的所有数值输入初始为空。
- 首次打开时显示待输入提示，不显示字段错误或计算结果。
- 材料选项包含铜线和铝线。
- 页面不再渲染“铜线电阻率”输入。
- 页面显示材料中立长度标签和新增重量结果。
- 工具说明与 SEO 不再声称只计算铜线。
- `pnpm test`、`pnpm lint` 和 `pnpm build` 全部通过。

## 8. 非目标

- 不修改圆形与矩形线圈的几何近似。
- 不计算漆皮、绝缘、浸漆或制造余量。
- 不计算引出线、跨接线、接头或端部附加重量。
- 不支持非三相电机。
- 不增加材料价格、成本或材料利用率。
- 不改变 P-P 电阻的对称星形接法假设。
