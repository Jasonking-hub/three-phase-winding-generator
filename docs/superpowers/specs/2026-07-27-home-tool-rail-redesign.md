# 首页工具轨道重排设计

日期：2026-07-27  
状态：用户已选择方案 A，待规格确认

## 目标

删除首页左侧独立介绍卡，让三个工具入口占据首屏主体宽度。保留“悬停或键盘聚焦的工具成为主功能区”这一交互，但消除卡片尺寸、文字换行和内容显隐造成的生硬跳切。

## 范围

- 只修改首页结构、首页工具卡片交互与对应样式。
- 保留站点顶栏、三个工具路由、工具名称、功能图形、SEO 数据和“更多工具”区域。
- 不修改三个计算器的公式、字段或结果页面。

## 页面结构

首页首屏改为一个全宽工具区：

1. 顶部保留紧凑的页面标题“中欣工具箱”和一句功能说明，承担唯一 `h1` 与首页语义，不再使用独立左侧 Hero 卡。
2. 三张工具卡在桌面端横向铺满容器。
3. 默认第一张卡为主卡；鼠标进入或键盘聚焦其他卡时，主卡状态随之切换。
4. “更多工具”保持在工具区下方。

## 动画

- 桌面端工具轨道使用 CSS Grid 可插值列宽，不再用当前 `flex-grow` 方案。
- 三个状态分别采用 `2.2fr 1fr 1fr`、`1fr 2.2fr 1fr`、`1fr 1fr 2.2fr`。
- 列宽过渡约 `650ms`，缓动使用 `cubic-bezier(0.16, 1, 0.3, 1)`。
- 卡片内部提供“紧凑标题”和“完整内容”两层稳定布局，通过 `opacity` 与轻微 `transform` 交叉淡入，避免宽度变化期间反复换行。
- 只动画 grid tracks、transform、opacity 与颜色，不用 JavaScript 连续追踪鼠标位置。
- `prefers-reduced-motion: reduce` 下取消过渡，直接切换状态。

## 响应式与可访问性

- `1024px` 以下改为单列纵向工具卡，不执行横向扩张。
- 鼠标悬停与 `:focus-visible` 使用同一激活状态。
- 保留 Space 键进入工具页、清晰焦点环和完整链接语义。
- 页面不得出现水平滚动。

## 验收标准

1. 桌面首页不再出现截图中的左侧大块介绍卡。
2. 工具区占满页面内容宽度，三张卡横向平铺。
3. 任意卡片悬停后平滑成为宽主卡，无瞬间跳宽、标题剧烈换行或说明闪现。
4. 指针快速横跨三张卡时，动画能够连续接管当前状态，不先复位再展开。
5. 键盘 Tab 聚焦产生相同主卡效果，Space 可进入对应页面。
6. 移动端为清晰单列布局，无横向溢出。
7. `npm test`、`npm run lint`、`npm run test:build` 通过。

## 设计约束

- 视觉语言继续使用现有深蓝、橙色和冷灰工程色系。
- 不引入新动画库或新依赖。
- 不增加装饰性文案、公式、标签或无关效果。
