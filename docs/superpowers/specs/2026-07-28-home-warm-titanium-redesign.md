# 首页暖钛视觉与流畅动效设计

## 目标

将首页从藏蓝、铜橙工程面板改为更轻的暖钛编辑风格，并缓和工具卡切换速度。首页应显得安静、精密、易读；三个现有工具入口及其内部内容保持不变。

## 范围

- 只重做首页标题区、工具轨道及其视觉状态。
- 调整共享顶部导航的材质与颜色，使其与首页一致；计算器主体、表单、结果和业务交互不改。
- 删除首页整个“更多工具”区块，不保留空标题、占位卡或“即将上线”文案。
- 保持全部路由、工具注册表、SEO 结构化数据和页脚内容不变。

## 标题区

- 保留 H1“中欣工具箱”。
- 在 H1 下新增一句副标题：“工程计算，不必复杂”。
- 标题区采用居中布局，H1 使用石墨色、大字号、紧字距；副标题使用中性灰并保持清晰对比。
- 不增加英文眉题、产品介绍段落、按钮或装饰图形。

## 配色与材质

首页采用暖钛编辑风格：

- 页面背景：暖灰白，接近纸张与浅钛材质。
- 主要文字：深石墨色，不再使用大面积藏蓝。
- 次要文字：中性暖灰。
- 工具图形与焦点：低饱和深棕金，只用于强调，不作为大面积背景。
- 活动工具卡：接近纯白的实体表面，使用细边框和柔和深度阴影。
- 非活动工具卡：略深的暖灰表面，保持边界清晰。
- 顶部导航：暖色半透明背景、适度模糊和细亮边，作为唯一明显的半透明层。

不使用彩色渐变、霓虹、噪点、光斑或叠加玻璃卡片。

## 工具轨道

保留现有三个工具卡和动态焦点轨道。每张卡内部以下内容不得修改：

- 两位编号。
- `Q : P`、梅花形排线 SVG、`Ω` 与 `ρL/A` 图形。
- 工具名称。
- 工具说明。
- 链接目标和无障碍名称。

桌面端默认突出槽极配生成器。指针进入或键盘聚焦其他卡片时，只改变三张卡片的宽度、表面层级、文字显隐和阴影。移动端继续纵向显示三张完整卡片，不依赖 hover。

## 动效

- 桌面卡片宽度切换使用约 `420ms` 的平滑 ease-out 曲线，快速切换时从当前呈现状态继续，不等待前一次动画结束。
- 卡片背景、边框和阴影使用 `300ms` 左右的同向缓动。
- 完整说明与紧凑标题的透明度、最大 `4px` 位移使用约 `260ms` 缓动。
- hover 上浮不超过 `2px`；按下即时缩放至 `0.98`，释放后回到当前焦点状态。
- 不使用循环动画、弹跳、延迟队列或阻塞点击的状态锁。
- 只对三个元素执行轻量布局过渡；其余动画限制为 `transform`、`opacity`、颜色、边框和阴影。

`prefers-reduced-motion: reduce` 下取消卡片宽度、位移和缩放动画，仅保留不超过 `160ms` 的颜色与透明度反馈。

## 响应式与无障碍

- `>= 1024px`：横向三卡动态轨道。
- `< 1024px`：纵向完整卡片，所有名称和说明始终可见。
- `< 640px`：缩小页面边距和卡片内边距，触摸目标仍不小于 `44px`。
- 保持链接语义、空格键激活、可见焦点和现有 aria-label。
- 暖灰文字、棕金强调和焦点环必须满足浅色背景下的可读性；信息不只靠颜色表达。
- 顶部导航在 `prefers-reduced-transparency: reduce` 下使用近实色背景并取消模糊，在 `prefers-contrast: more` 下提高边框和文字对比。

## 文件职责

- `app/page.tsx`：新增副标题并删除“更多工具”区块。
- `app/home.module.css`：实现首页暖钛布局、工具轨道状态、动效和响应式规则。
- `app/globals.css`：只调整共享顶部导航材质；不改变计算器通用输入、输出和表格样式。
- `tests/home.test.mjs`：验证副标题、删除空区、内部工具内容保持、动效时长和减弱动态规则。

## 验收

1. 首页只显示标题、副标题和三个现有工具入口，不显示“更多工具”。
2. 工具卡内部文字、图形、链接和顺序与改版前一致。
3. 桌面端连续横移指针时，宽度和内容显隐连续，无明显跳变或快速闪切。
4. 键盘焦点产生相同的活动状态，点击立即进入对应工具。
5. 移动端三张卡片完整可读，无横向页面溢出。
6. 减弱动态设置下无宽度、位移或缩放动画。
7. `pnpm test`、`pnpm lint`、`pnpm build` 和 `pnpm test:build` 通过。
