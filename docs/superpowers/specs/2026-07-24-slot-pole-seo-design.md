# 槽极配生成器 SEO 设计

## 目标

让公开首页可被搜索引擎抓取并清楚理解其用途，覆盖中文搜索意图：`槽极配`、`槽极配合计算`、`槽数极数怎么算`。不承诺收录时间或具体排名。

## 范围

- 保持现有公开网址和计算器功能不变。
- 将首页标题改为“槽极配生成器 | 槽极配合计算 | 三相双层绕组”。
- 添加简洁、人工可读的产品说明与常见问题，解释槽极配、槽数 Q、总极数 P、推荐节距 y 和相别切换。
- 添加规范链接、中文描述、Open Graph 基础元数据，以及 `WebApplication` JSON-LD。
- 新增允许抓取的 `/robots.txt`，其中声明 `/sitemap.xml`。
- 新增 `/sitemap.xml`，只列出公开首页的规范 URL。

## 不做的事

- 不堆砌关键词、不生成伪内容、不创建重复页面。
- 不改变绕组计算规则、输入方式或公开访问权限。
- 不承诺搜索引擎会收录或让指定关键词排名。
- 不接入付费推广、广告、追踪脚本或外部 SEO 服务。

## 页面与数据流

首页继续在浏览器执行绕组计算。服务端渲染的页面头部提供元数据与 JSON-LD；首页正文提供可抓取的中文说明。`robots.txt` 引导爬虫至站点地图，站点地图列出首页。所有规范 URL 使用现有公开 HTTPS 地址。

## 内容结构

首页计算器下方新增一个说明区，包含：

1. “槽极配是什么”
2. “槽极配合计算：槽数与极数怎么算”
3. “如何使用本生成器”
4. 两个简短 FAQ：支持哪些输入、BC 互换和 UVW 显示的用途

关键词只在与用户问题直接相关的标题或正文中出现。页面保持工具优先，说明区不干扰输入和结果。

## 验证

- 先写测试，验证标题、描述、规范 URL、结构化数据、`robots.txt` 和 `sitemap.xml`。
- 先运行测试并确认其因 SEO 文件与内容缺失而失败。
- 进行最小实现后，运行全部测试和生产构建。
- 发布后确认托管服务报告部署成功。

## 搜索引擎提交

发布后，站长可在 Google Search Console 添加完整 URL 前缀属性，并提交 `https://three-phase-winding-generator.jasonking15871921724.chatgpt.site/sitemap.xml`。也可在 Bing Webmaster Tools 添加同一站点并提交该站点地图。提交帮助发现页面，不能保证排名或即时收录。
