# 线圈计算结果 Excel 导出设计

## 目标

为 03 线圈电阻计算器增加两个独立的 Excel 导出入口。圆形线圈和矩形线圈完成有效计算后，可把当前输入参数与全部计算结果导出为 `.xlsx` 文件，并由浏览器自动下载。

## 交互

- 圆形线圈和矩形线圈的“计算结果”标题旁各放置一个“导出 Excel”按钮。
- 当前表单未填写完整或计算无效时，对应按钮禁用。
- 点击按钮只导出对应计算器的数据，不混入另一种线圈的数据。
- 导出失败时，在对应按钮旁显示简短错误；现有输入和计算结果保持不变。
- 文件名格式：
  - `圆形线圈计算结果_YYYYMMDD-HHmmss.xlsx`
  - `矩形线圈计算结果_YYYYMMDD-HHmmss.xlsx`

## 工作簿结构

每个文件只包含一个工作表，工作表名为“圆形线圈”或“矩形线圈”。表格使用三列：

| 项目 | 数值 | 单位 |
| --- | ---: | --- |

数值列保存为 Excel 数字，不写公式。导出值直接取当前已经验证通过的计算结果，避免在导出模块中复制计算公式。

### 圆形线圈

输入与材料：

- 线圈材料
- 电阻率，`μΩ·mm`
- 密度，`kg/mm³`
- 裸线径，`mm`
- 最外圈直径，`mm`
- 最内圈直径，`mm`
- 匝数，`匝`

计算结果：

- 截面积，`mm²`
- 最外圈单匝长度，`mm`
- 最内圈单匝长度，`mm`
- 平均单匝长度，`mm`
- 单线圈线材长度，`mm`
- 单线圈电阻，`Ω`
- 单线圈重量，`kg`

### 矩形线圈

输入与材料：

- 线圈材料
- 电阻率，`μΩ·mm`
- 密度，`kg/mm³`
- 裸线径，`mm`
- 最外圈长，`mm`
- 最外圈宽，`mm`
- 最内圈长，`mm`
- 最内圈宽，`mm`
- 匝数，`匝`
- 每相支路数，`支路`
- 每支路线圈数，`线圈`

计算结果：

- 截面积，`mm²`
- 最外圈单匝长度，`mm`
- 最内圈单匝长度，`mm`
- 平均单匝长度，`mm`
- 单线圈线材长度，`mm`
- 单线圈电阻，`Ω`
- 单相电阻，`Ω`
- P-P 电阻，`Ω`
- 单线圈重量，`kg`
- 整台三相电机线圈重量，`kg`

## 技术方案

- 使用 SheetJS Community Edition 生成真实 `.xlsx` 文件。
- SheetJS 只在用户点击导出按钮时动态加载，避免增加计算器首屏 JavaScript 体积。
- 新建纯数据构建模块，负责把当前输入与计算结果转换为三列表格。该模块不访问 DOM，便于单元测试。
- 浏览器下载模块负责生成工作簿、设置列宽、触发下载；不引入服务端接口。

## 错误处理

- 无效计算不允许触发导出。
- 动态加载、工作簿生成或下载发生异常时，显示“Excel 导出失败，请重试。”
- 成功导出后清除旧错误。

- 先写失败测试，再实现导出数据构建、文件命名和界面接线。
- 验证圆形、矩形导出均包含全部规定字段，数值字段保持数字类型。
- 验证文件名时间格式稳定。
- 验证按钮在无效计算时禁用，有效计算时调用对应下载逻辑。
- 运行全量单元测试、ESLint、生产构建和静态导出测试。
- 合并到 `main` 后重新运行验证，再部署 Netlify 生产环境。
- 线上检查页面状态为 HTTP 200，两个导出入口与 `.xlsx` 下载逻辑均已发布。
