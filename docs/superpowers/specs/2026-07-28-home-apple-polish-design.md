# 首页 Apple 风格精修设计

## 目标

删除首页三段冗余说明文字，保持工具入口清晰。以现有工程工作台视觉为基础，加入克制的 Apple 式层级、材质和反馈；不改变工具内容、路由或页面结构。

## 范围

删除 `app/page.tsx` 中：

1. 主标题下方“槽极配、漆包线排线与线圈电阻，一处进入。”
2. “更多工具”区块上方“持续扩展”
3. “更多工具”下方“后续将围绕电机设计与制造中的常用计算持续补充工具。”

更新首页、工具轨道和顶部导航样式。其余计算器页面、工具注册表和页脚不改。

## 视觉设计

- 保留 `DESIGN.md` 的工程工作台配色，不引入渐变、霓虹或玻璃拟态卡片。
- 顶部导航使用浅色半透明材质与背景模糊，作为唯一半透明层，强调导航层级。
- 首页标题区只保留 H1，增加适度留白；工具轨道和“更多工具”使用更柔和的边框、圆角与藏蓝投影。
- 活动工具卡保持深藏蓝背景；非活动卡保持浅色背景。卡片按下缩放至 `0.97`，hover/focus 上浮不超过 `2px`。

## 选项卡交互与动画

- 桌面端指针进入或键盘聚焦卡片时更新活动状态；点击仍直接进入工具页。
- 三栏宽度切换使用 `220ms cubic-bezier(0.23, 1, 0.32, 1)`，只动画网格列宽。
- 卡片颜色、阴影、内容显隐使用 `180ms` 至 `220ms` 同一曲线，只动画 `transform`、`opacity`、颜色与阴影。
- 内容显隐位移不超过 `4px`，不使用 keyframes、弹跳或延迟。快速切换时 CSS transition 从当前呈现值重新定向，避免跳变。
- `prefers-reduced-motion: reduce` 下取消列宽和位移动画，保留不超过 `160ms` 的透明度/颜色反馈。

## 可访问性与验证

- 保持链接语义、可见焦点、空格键激活和移动端完整内容回退。
- 新增首页源码测试：三段指定文案不存在；动效时长为 220ms 以内；reduced-motion 规则保留。
- 运行 `pnpm test`、`pnpm lint` 和 `pnpm build`。在桌面宽度连续在三张卡片间移动指针，确认内容和尺寸连续切换；在减弱动态设置下确认无位移或列宽动画。
