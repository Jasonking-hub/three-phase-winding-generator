# 槽极配页面与三相接线图重设计

## 设计判断

这是面向电机绕组使用者的工程计算器重设计。目标语言是可信、精确、紧凑，不采用营销页装饰。

- `DESIGN_VARIANCE: 3`
- `MOTION_INTENSITY: 2`
- `VISUAL_DENSITY: 7`
- 保留现有浅色技术界面、输入流程、计算逻辑和 SEO 结构。
- 使用现有 React、原生 CSS 和 SVG，不增加设计系统、图表库或动画依赖。

## 目标

1. 精简顶部标题和线圈接线表。
2. 将三相接线图改成包含铁芯、槽内左右双层线圈和实际串联引线的工程示意图。
3. 槽数变化时，铁芯齿数、边齿和线圈数同步变化。
4. 十二槽及以上时利用输入面板下方空白区域，让接线图向左扩展。
5. 鼠标位于接线图内时，滚轮控制接线图缩放。

## 不在范围内

- 不改变 `generateWinding` 的绕组计算结果。
- 不改变槽数、极数、ABC/UVW 和 BC 相互换的输入方式。
- 不改 URL、SEO 内容顺序、端子命名规则或其他无关页面区域。
- 不引入拖拽画布、自动动画、3D 效果或额外配置项。

## 当前问题

- 顶部辅助标题和说明文字重复，占用首屏空间。
- 表格重复展示左右两端数据，列数过多，字号和徽标尺寸不统一。
- 当前三条贯穿母线连接所有线圈，视觉上容易被理解为并联。
- 当前图没有铁芯，也没有表达同一槽内两根线圈边左右并排的双层关系。
- 两行槽端标记按槽位排列，没有与对应线圈居中对齐。
- 接线图被限制在右侧结果栏，十二槽时左侧输入面板下方存在大块未使用空间。

## 页面标题

- 删除“三相双层绕组”。
- 删除“输入槽数和总极数，即时生成与原工作簿一致的线圈接线表。”
- 仅保留“槽极配生成器”。
- 标题使用藏蓝色、粗体和紧凑行高，颜色与表头同一冷色体系。
- 不增加新副标题、装饰标签或渐变。

## 线圈接线表

### 保留列

| 列名 | 内容 |
| --- | --- |
| 线圈 | 线圈序号 |
| 相别 | A/B/C 或 U/V/W |
| 线圈标记 | 原接线标记中箭头左侧的标记，例如 `A+` |
| 组极性 | `+` 或 `-` |
| 线圈电角° | 当前计算值 |
| 状态 | `OK` |

### 删除内容

- 删除“上层槽”和“下层槽”两列。
- 删除“上层标记”和“下层标记”两列。
- 原“接线标记”删除箭头和箭头右侧标记，只保留左侧标记。
- 将该列改名为“线圈标记”。

### 排版

- 表头、正文、相别徽标和状态徽标统一为同一字号。
- 表头用字重和反白区分，不通过更小字号区分。
- 相别、线圈标记、组极性、角度和状态居中。
- 六列宽度均衡，桌面端不出现无意义横向滚动。
- 保留隔行底色和行悬停反馈，不增加阴影或渐变。

## 三相接线图

### 数量规则

槽数 `Q` 决定图形数量：

- `Q` 个完整铁芯齿。
- 左右各一个边齿，共两个边齿。
- `Q` 个线圈。

示例：

- 六槽显示 6 个完整齿、2 个边齿和 6 个线圈。
- 十二槽显示 12 个完整齿、2 个边齿和 12 个线圈。
- 其他槽数按同一规则动态生成，不把六槽结构写死。

### 铁芯与线圈

- 铁芯齿使用浅灰填充和深灰描边，保持工程图清晰度。
- 左右边齿显示为部分齿，用于表达结构连续性。
- 每个线圈使用圆角闭合轮廓，线圈两条有效边落在对应槽位。
- 同一槽内的两根线圈边采用小幅水平错位，左右并排显示，不上下叠放。
- 节距 `y = 1` 时，线圈包围一个齿，外观与用户参考图一致。
- 节距大于 1 时，线圈按实际槽距跨越多个齿，端部使用分层高度避让，但槽内有效边仍保持左右双层。

### 相别颜色

| 相别 | 颜色 |
| --- | --- |
| A / U | 橙色 |
| B / V | 蓝色 |
| C / W | 绿色 |

- 线圈轮廓、线圈标记、相名、串联引线和端子文字使用对应相色。
- ABC/UVW 切换和 BC 相互换后，图、表和端子同步更新。
- 铁芯保持中性灰，不随相别变化。

### 线圈标记

- 删除当前图中第二行标记，即参考截图红框整行。
- 仅保留当前第一行标记，即参考截图蓝框内容。
- 每个标记使用该线圈的 `upperMark` 值，例如 `A+`、`C-`。
- 标记放在线圈正下方，以线圈左右有效边的中点居中，不再按单个槽位对齐。
- 标记与铁芯之间保留统一垂直间距，不与串联引线重叠。

### 串联引线

- 删除图上方三条贯穿全图的相线母线。
- 参考用户提供的接线示意，在铁芯和线圈下方绘制正交折线。
- 同相线圈按现有绕组数据顺序首尾串联。
- 三相使用独立纵向通道，A/U、B/V、C/W 引线互不遮挡。
- 线路交叉处没有连接关系时不绘制节点。
- 每相线路两端分别标注标准端子：`U1/U2`、`V1/V2`、`W1/W2`。

## 十二槽及以上的宽布局

- `Q < 12` 时，接线图保持在右侧结果栏下方。
- `Q >= 12` 时，接线图成为工作区的全宽网格项。
- 接线图右边缘继续与结果栏右边缘对齐，左边缘扩展到输入面板左边缘，利用输入面板下方空白区域。
- 图形内部保持固定基础齿距，不为塞进容器而压缩文字或线圈。
- 槽数继续增加时，容器允许水平滚动。
- 小屏统一使用全宽布局和水平滚动。

## 滚轮缩放

- 鼠标指针位于三相接线图可视区域内时，滚轮控制缩放。
- 向上滚动放大，向下滚动缩小。
- 缩放范围限制为 `60%` 到 `220%`。
- 缩放以鼠标当前位置为视觉锚点，避免每次缩放跳回左上角。
- 缩放只改变 SVG 视图，不改变外层卡片高度，不引起页面布局跳动。
- 指针离开接线图后，滚轮恢复正常页面滚动。
- 槽数或极数变化时缩放恢复到适配视图；ABC/UVW 和 BC 相互换不重置缩放。
- 使用组件范围内的原生 `wheel` 处理，不注册全局滚动监听。

## 组件与数据边界

- `generateWinding` 继续作为唯一计算来源。
- `buildWindingDiagram` 只负责把行数据映射为齿、线圈、标记和相内串联顺序。
- `WindingDiagram` 负责 SVG 几何、宽布局状态和缩放交互。
- 页面组件只负责表格列裁剪和根据槽数添加宽布局类。
- 不为一次性 SVG 几何建立额外通用框架。

## 响应式与可访问性

- SVG 保留语义标题和描述。
- 无效输入继续显示文本提示，不绘制错误结构。
- 接线图区可获得键盘焦点，焦点样式清晰。
- 相别不只依赖颜色，线圈下方保留文字标记。
- 所有正文和控制保持 WCAG AA 对比度。
- 不添加装饰动画，缩放只响应用户输入。

## 验证

### 数据与结构

- 六槽：6 个完整齿、2 个边齿、6 个线圈、6 个居中标记。
- 十二槽：12 个完整齿、2 个边齿、12 个线圈、12 个居中标记。
- 大于十二槽：数量继续按 `Q` 增长，图形可横向查看。
- 节距大于 1：线圈跨距正确，槽内两层仍左右并排。

### 表格

- 只显示六个保留列。
- “线圈标记”只显示原接线标记左侧内容。
- 表头、正文、徽标字号一致。
- 默认桌面宽度无横向滚动条。

### 交互

- 十二槽及以上接线图向左扩展为工作区全宽。
- 图内滚轮在 `60%` 到 `220%` 之间缩放。
- 缩放围绕鼠标位置进行，容器高度不跳动。
- 图外滚轮正常滚动页面。
- Q/P 变化重置适配视图，相别显示变化不重置。

### 状态

- 默认 ABC、UVW、BC 相互换均保持相色和标记一致。
- 无效输入显示提示。
- 窄屏可查看完整图形，不压缩字号。
