# 三相绕组接线图设计

## 目标

在现有槽极配计算结果中增加清晰的三相接线图。用户改变槽数 Q、总极数 P、相别显示或 BC 相互换后，图、表和端子说明必须同步更新。

## 页面调整

- 顶部主标题改为“槽极配生成器”。
- 缩小页面顶部留白和标题区底部间距，使输入与结果整体上移。
- 保留现有输入区、接线表、端子说明和 SEO 内容的顺序。
- 在接线表后、端子说明前插入“三相接线图”。

## 接线图

采用横向展开的三相分线图：

- 每个线圈按工作簿生成结果显示为跨槽的 U 形线圈，不绘制铁芯、槽钢、胶水或仿真底图。
- 图中保留槽号、相别、线圈两端正负标记和每相串联主线。
- 每相主线置于图上方，线圈按相别分层错开，避免重叠遮挡。
- 图宽度随槽数增长；窄屏与高槽数场景使用横向滚动，不压缩线圈标签。
- 无效 Q、P 时展示与接线表一致的提示，不绘制错误图形。

## 相别与颜色

颜色由当前显示相别决定：

| 相别 | 颜色 |
| --- | --- |
| A / U | 橙色 |
| B / V | 蓝色 |
| C / W | 绿色 |

- 选择 ABC 或 UVW 时，图中的相线标题、端子标记、线圈标记与表格同时切换。
- 打开 BC 相互换时，B/C 或 V/W 的线圈归属、颜色和相线归属同时交换。

## 实现边界

- 复用 `generateWinding` 的单一计算结果；新增小型纯数据映射函数供图形与测试使用。
- 新建独立 `WindingDiagram` 组件，使用语义化容器与 SVG 绘制实际绕组关系。
- 不引入第三方绘图库或新依赖。
- 仅修改与标题、布局、接线图和相色映射直接相关的代码。

## 验证

- 单元测试覆盖默认 ABC、UVW、BC 相互换的接线图数据映射。
- 构建后确认有效输入显示图形，无效输入显示提示。
- 确认图中 A/U 为橙、B/V 为蓝、C/W 为绿，且端子文字与计算表一致。
- 确认窄屏可横向查看完整图形。
