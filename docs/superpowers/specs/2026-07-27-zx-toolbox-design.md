# 中欣工具箱多工具网站设计规格

## 1. 决策摘要

将现有单页“槽极配生成器”改造成“中欣工具箱”。新站使用一个首页和三个独立工具页：

- 槽极配生成器
- 漆包线排线计算器
- 线圈电阻计算器

两个新计算器严格复刻用户提供的 Excel 公式、默认值、模式、警告和隐含假设。这里的“严格复刻”指有效数值输入下的公式、常量、默认值、结果和业务警告一致；网页只改善无效输入提示与数字排版，不改变有效输入的计算结果。首页采用已批准的工程工作台方案：标题“中欣工具箱”，三块工具区动态扩展，漆包线图形使用真实梅花形密排。

目标规范网址为 `https://zx-toolbox.netlify.app`。

## 2. 目标与成功标准

### 目标

1. 建立可持续扩展的工程计算工具入口。
2. 保留现有槽极配全部计算、表格、接线图和交互能力。
3. 将两份 Excel 转换为无需上传文件、无需服务器的浏览器计算器。
4. 让每个工具拥有独立 URL、SEO 元数据和自动化测试。
5. 首页建立“中欣工具箱”品牌，并清楚区分三个工具。

### 成功标准

- 四个公开路由均可直接访问和静态导出。
- Excel 默认示例的网页结果与工作簿结果一致。
- 槽极配现有测试样例继续通过。
- 首页鼠标、键盘、触摸和 reduced-motion 行为满足本规格。
- `pnpm test`、`pnpm lint` 和 `pnpm build` 全部通过。
- Netlify 发布目录仍为 `dist/client`，站点 canonical 和 sitemap 使用新域名。

## 3. 范围与非目标

### 本轮范围

- 首页、共享导航、页脚和工具注册表。
- 三个独立工具页。
- 两个 Excel 计算器的纯函数与测试。
- 现有槽极配迁移和回归验证。
- 每页 SEO、robots、sitemap、结构化数据和社交预览基础信息。
- 响应式、键盘操作、可读错误和 reduced-motion。

### 不在范围

- 用户账号、历史记录、云同步或数据库。
- 导出 Excel、PDF 或图片。
- 全局最优排线搜索。
- 电阻温度修正、材料选择或星形/三角形切换。
- 修改原 Excel 公式中的工程假设。
- 深色模式。
- 为原 Netlify 域名单独维护第二个重定向站点。
- “更多工具”中的第四个实际计算器。

| 路由 | 页面标题 | 职责 |
| --- | --- | --- |
| `/` | 中欣工具箱 | 品牌、工具发现、三个入口、更多工具占位 |

## 5. 首页设计

视觉要求引用根目录 `DESIGN.md`，不在本规格重复 token。

### 首屏

- 导航品牌和 H1 均使用“中欣工具箱”。
- H1 下方一句话说明三个工具的共同用途。
- 右侧核心计算索引可以显示三个工具名称与代表公式；工具卡底部不得显示公式。

### 动态工具区

- 桌面端默认槽极配为主工具。
- 指针进入任一工具或工具获得键盘焦点时，该工具扩展，其余工具收缩。
- 尺寸变化约 `540ms`，曲线 `cubic-bezier(.22, 1, .36, 1)`。
- 只动画 `flex-grow`、`transform`、`opacity` 和颜色；不监听全局滚动。
- 点击工具或键盘按 Enter/Space 进入对应路由。
- reduced-motion 下立即切换，不使用位移和延迟显隐。
- 移动端三块纵向排列并显示完整摘要，点击直接导航，不设计两次点击流程。

### 工具识别图形

- 槽极配：`Q : P`。
- 漆包线排线：真实圆形线材梅花形密排，相邻层错开半个线径，并有左、下边界。
- 线圈电阻：`Ω` 和小型 `ρL/A` 分式。
- 禁止卡片底部公式、随意圆点阵和虚构计算结果。

### 更多工具

显示“更多工具”与持续扩展说明。首个版本不链接到空页面，也不伪造可用工具。

## 6. 共享架构与数据流

### 模块边界

- 工具注册表：名称、路由、短说明、首页识别图形类型和排序。
- 共享站点外壳：导航、页面容器、页脚和 SEO 基础配置。
- 每个工具的纯计算模块：只接收数值与枚举，返回结构化结果，不访问 DOM。
- 每个工具页：管理输入状态、调用纯函数并渲染结果。
- 现有 `WindingDiagram`：继续只负责槽极配 SVG 和缩放交互。

### 数据流

```text
用户输入
  -> 字符串解析与有限数检查
  -> Excel/槽极配约束判断
  -> 纯计算函数
  -> 原始精度结果
  -> 按字段规则格式化显示
```

所有计算同步在浏览器完成。不存在网络加载、保存或后台任务。

## 7. 槽极配生成器规格

### 保留输入

- 槽数 `Q`
- 总极数 `P`
- `ABC` / `UVW`
- BC/VW 相别互换

### 保留规则

- `Q`：3 至 120 的整数，且为 3 的倍数。
- `P`：2 至 120 的偶数。
- 推荐节距：`max(1, floor(Q / P))`。
- 相带、电角度、极性和接线顺序保持现有 `generateWinding` 结果。

### 保留输出与交互

- 生成状态与推荐节距。
- 六列线圈接线表。
- 三相串联、端子和中性点。
- 接线图齿数、线圈数、轨道、箭头、顺序号和缩放。
- 大槽数横向滚动与既有响应式行为。

迁移只改变路由、共享外壳和视觉 token，不改变计算结果。

## 8. 漆包线排线计算器规格

来源工作簿：`漆包线排线计算器.xlsx`。

### 8.1 公共定义

- `D`：含漆膜实际外径，单位 `mm`。
- `M`：垂直层数，整数。
- `N`：水平根数；在边界内错排模式中代表奇数层根数。
- `Pv = D × √3 / 2`。
- `Offset = D / 2`。
- 排布模式只允许“每层同根数”或“边界内错排”。

工作簿明确忽略压扁、张力、漆膜误差、浸漆和工艺余量，网页保持相同说明。

### 8.2 按层数计算尺寸

默认值：

| 字段 | 默认值 |
| --- | --- |
| `D` | `0.87` |
| `M` | `11` |
| `N` | `4` |
| 模式 | 每层同根数 |

公共高度：

```text
输入无效时 H = 0
否则 H = D + (M - 1) × D × √3 / 2
```

每层同根数：

```text
W = N × D + (M >= 2 ? D / 2 : 0)
Total = M × N
```

边界内错排：

```text
W = N × D
Total = ceil(M / 2) × N + floor(M / 2) × max(N - 1, 0)
```

警告严格复刻：当模式为边界内错排、`M >= 2` 且 `N < 2` 时，显示“注意：水平根数小于 2 时，无法形成完整品字形错排。”；否则显示“正常”。

Excel 默认示例预期：

| 输出 | 值 |
| --- | --- |
| `Pv` | `0.7534421012924616` |
| `Offset` | `0.435` |
| `H` | `8.404421012924615` |
| `W` | `3.915` |
| `Total` | `44` |

### 8.3 按最大尺寸反推

默认值：

| 字段 | 默认值 |
| --- | --- |
| `D` | `0.62` |
| `Wmax` | `1.8` |
| `Tmax` | `3.6` |
| 模式 | 每层同根数 |

垂直层数：

```text
D <= 0 或 Tmax < D 时 M = 0
否则 M = 1 + floor((Tmax - D) / (D × √3 / 2))
```

水平根数：

```text
D <= 0、Wmax < D 或 M = 0 时 N = 0

每层同根数且 M >= 2：
N = max(0, floor((Wmax - D / 2) / D))

每层同根数且 M < 2：
N = floor(Wmax / D)

边界内错排：
N = floor(Wmax / D)
```

实际尺寸使用 8.2 的 `H`、`W` 公式。剩余量：

```text
宽度剩余量 = Wmax - W_actual
厚度剩余量 = Tmax - H_actual
```

警告严格复刻：

1. 边界内错排、`M >= 2` 且 `N < 2`：“注意：水平宽度不足以形成完整品字形错排。”
2. 每层同根数、`M >= 2` 且 `Wmax < 1.5 × D`：“注意：宽度不足以排下两层错位后的最小外包络。”
3. 其他情况：“正常”。

Excel 默认示例预期：

| 输出 | 值 |
| --- | --- |
| `Pv` | `0.5369357503463519` |
| `Offset` | `0.31` |
| `M` | `6` |
| `N` | `2` |
| `H_actual` | `3.30467875173176` |
| `W_actual` | `1.55` |
| 宽度剩余量 | `0.25` |
| 厚度剩余量 | `0.29532124826824013` |
| `Total` | `12` |

### 8.4 显示规则

- 计算内部保留 JavaScript 数值精度。
- 尺寸默认显示三位小数，整数结果不显示小数。
- 页面将 Excel 的“总匝数 Total”显示为“总根数 Total”，仅修正标签歧义，不改变公式。
- 原始警告文字逐字保持。

## 9. 线圈电阻计算器规格

来源工作簿：`线圈电阻计算.xlsx`。

### 9.1 圆形线圈

默认输入：

| 字段 | 默认值 |
| --- | --- |
| 裸线径 `d` | `0.61 mm` |
| 最外圈直径 | `71.8 mm` |
| 最内圈直径 | `65.2 mm` |
| 匝数 | `228` |

铜线电阻率固定为工作簿值 `17.24 μΩ·mm`。

公式：

```text
半径 r = d / 2
圆形线圈常量 PI_CIRCLE = 3.141592653
截面积 A = PI_CIRCLE × r²
最外圈匝长 Lout = PI_CIRCLE × Dout
最内圈匝长 Lin = PI_CIRCLE × Din
平均匝长 Lavg = (Lout + Lin) / 2
铜线长度 L = 匝数 × Lavg
单线圈电阻 R = 17.24 × L / A / 1,000,000
```

默认示例单线圈电阻预期为 `2.8944296694436975 Ω`。

### 9.2 电机线圈

默认输入：

| 字段 | 默认值 |
| --- | --- |
| 裸线径 `d` | `0.8 mm` |
| 最外圈长 | `158 mm` |
| 最外圈宽 | `23.5 mm` |
| 最内圈长 | `140 mm` |
| 最内圈宽 | `5.5 mm` |
| 匝数 | `44` |
| 铜线电阻率 | `17.24 μΩ·mm` |
| 每相支路数 | `1` |
| 每支路线圈数 | `1` |

公式：

```text
半径 r = d / 2
电机线圈截面积常量 PI_MOTOR = 3.1415926535
截面积 A = PI_MOTOR × r²
最外圈匝长 Lout = 2 × (外圈长 + 外圈宽)
最内圈匝长 Lin = 2 × (内圈长 + 内圈宽)
平均匝长 Lavg = (Lout + Lin) / 2
铜线长度 L = 匝数 × Lavg
单线圈电阻 Rcoil = ρ × L / A / 1,000,000
单相电阻 Rphase = Rcoil × 每支路线圈数 / 每相支路数
P-P 电阻 = 2 × Rphase
```

默认示例预期：

| 输出 | 值 |
| --- | --- |
| 单线圈电阻 | `0.4934780447340384 Ω` |
| 单相电阻 | `0.4934780447340384 Ω` |
| P-P 电阻 | `0.9869560894680768 Ω` |

### 9.3 约束与显示

- 裸线径、尺寸、匝数、电阻率、支路数和每支路线圈数必须大于 0。
- 匝数、支路数和每支路线圈数必须为整数。
- 内部保留数值精度；长度显示三位小数，截面积和电阻显示六位小数。
- 不自动增加引出线、跨接线或接头长度。
- `P-P = 2 × 单相电阻` 保留工作簿的对称星形接法假设。

## 10. 错误处理

- 空字符串视为未输入；网页显示必填错误，不复刻 Excel 的空单元格或 `#DIV/0!` 展示。有效数值进入计算后必须与 Excel 一致。
- `NaN`、Infinity 和非数字输入不能进入计算函数。
- Excel 定义的零结果和警告属于有效业务结果，不能统一替换成“计算失败”。
- 页级错误不清空用户输入。
- 计算函数不抛出可预期输入错误，返回 `{ valid, errors, result }` 结构。
- 不使用 toast 显示持久表单错误。

## 11. SEO 与部署

- `SITE_URL` 改为 `https://zx-toolbox.netlify.app`。
- 首页 metadata 聚焦“中欣工具箱、电机计算工具、绕组计算”。
- 三个工具页使用各自 title、description、canonical 和关键词，不共享槽极配全文。
- `WebSite` 描述首页，三个页面分别输出 `WebApplication` JSON-LD。
- sitemap 收录四个路由；robots 指向新 sitemap。
- 新社交预览图使用“中欣工具箱”品牌，不继续只写“槽极配生成器”。
- 静态导出和 `dist/client` 发布目录保持。
- 原域名不作为 canonical；本轮不创建第二个旧站重定向部署。

## 12. 测试与验收

### 纯函数测试

- 槽极配现有样例、边界和相别切换继续通过。
- 排线两个 Excel 默认示例精确匹配。
- 排线两种模式、单层、多层、`N < 2`、边界不足和零输入覆盖。
- 电阻两个默认示例精确匹配。
- 电阻外圈小于内圈、零线径、零支路和非整数计数覆盖。

浮点断言使用明确容差，不对二进制浮点做字符串相等比较。

### 页面测试

- 首页存在三个正确链接和更多工具占位。
- 桌面 hover 与 focus 扩展同一工具。
- 键盘 Enter/Space 可进入工具。
- 移动端不依赖 hover。
- reduced-motion 禁用位移与延迟。
- 每个工具页输入标签、单位、默认值、结果与错误关系可被辅助技术识别。

### 构建测试

- 四个路由出现在静态产物。
- canonical、robots 和 sitemap 使用新域名。
- 无 `#REF!`、`#DIV/0!`、`NaN` 或 Infinity 出现在可见结果。
- Lighthouse 目标：LCP `< 2.5s`、INP `< 200ms`、CLS `< 0.1`。

## 13. 构建分解

项目采用轻量 Cavekit 流程，按独立边界构建：

1. 站点基础：共享布局、路由、工具注册表、SEO 基础。
2. 首页：批准的品牌与动态工具区。
3. 槽极配迁移：移动页面并通过现有回归测试。
4. 排线计算器：先写公式测试，再写计算模块和页面。
5. 电阻计算器：先写公式测试，再写计算模块和页面。
6. 集成：响应式、无障碍、SEO、静态构建与部署验证。

构建阶段由当前任务作为主代理统筹。可并行的独立工作使用 `gpt-5.6-terra`、中等推理子代理；共享布局和最终集成由主代理负责，避免并行修改相同文件。
